# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Mission

Master operational skill collection for the koinod fleet. 76 skills across Sales, Content, Research, Agent Infrastructure, Communication, Frontend, Dev Tools, Operations. Agents come here to find capabilities AND save new ones.

## Stack

Markdown + optional Python/JS scripts per skill. Agent Skills open standard.

## First-time orientation

Before doing substantive work in this repo, read in order:

1. **[ceoian/agent-learnings/CLAUDE.md](https://github.com/ceoian/agent-learnings/blob/main/CLAUDE.md)** — org-wide operating principles for any Claude session.
2. **[ceoian/agent-learnings/INDEX.md](https://github.com/ceoian/agent-learnings/blob/main/INDEX.md)** — failure log + patterns to avoid repeating mistakes.
3. **This repo's `README.md`** — what it is and how to run it.

## Principles

- Read INDEX.md first — that's the master scan. Each entry links to its dir.
- When saving a new skill, follow CONTRIBUTING.md's agent-save section. Don't invent ad-hoc skill layouts.
- EXTERNAL-SKILLS.md lists upstream registries — check there before building a new skill.

## Don'ts

- Don't add a skill that duplicates an existing one — improve the existing one instead.
- Don't ship a SKILL.md without YAML frontmatter (other agents won't discover it).
